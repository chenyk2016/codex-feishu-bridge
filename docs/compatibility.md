# 兼容与验证范围

本页描述 **0.2.0 本地版本准备**截至 2026-11-11 的证据范围。版本标签、自动检查、本机部署和独立新装是不同的验证层次；本页不表示已经公开发布，也不承诺其他环境自动兼容。

## 运行要求

| 项目 | 要求与判断方式 |
| --- | --- |
| 操作系统 | macOS；安装器使用用户级登录服务 |
| Node.js | 24 或更高，执行 `node --version` 核对 |
| Python | macOS 系统 Python 3，安装说明使用 `/usr/bin/python3` |
| Codex | 本机桌面环境及匹配的 CLI；先验证该 CLI 支持 `queue --thread --message` |
| 飞书 | 企业自建应用、机器人、本人私聊可用范围，以及消息与卡片长连接订阅 |
| 回复汇报 | 需要当前 Codex 支持 Stop Hook，并由用户审阅信任 |
| 图片 | 显式开启；飞书图片权限与本机输出目录授权 |
| Mermaid 图表 | 开启图片功能，另需本机 Google Chrome |
| 元数据功能 | 全主聊天汇报、最近回复与问题回复需要匹配当前客户端的本机 SQLite 索引 |

没有宣称一个最低 Codex 版本号：桌面发行和内置 CLI 可能不同步，应以实际命令、Hook 与记录格式检查为准。元数据查询及异步问题捕获依赖客户端内部格式，升级 Codex 后需要复验。安装器不支持 Windows/Linux；国际版 Lark 未验证。

## 已有验证与可据此判断的内容

| 证据 | 已验证内容 | 不能据此推断 |
| --- | --- | --- |
| 核心自动测试 | 路由、配对、防重复、异常结果、配置和隔离运行等代码行为 | 实际飞书账号权限、任意客户端或长期运行可靠性 |
| 导航自动回归 | 管理入口可重复打开，列表、翻页和确认另发卡片 | 已在所有手机型号、飞书版本上实测 |
| 既有本机安装的异步问答 | 新问题自动发到飞书；本人确认选项显示正常；选择单次回到原聊天并实际被消费 | 桌面原生问题框关闭；文字回答、多题在手机上逐项实测 |
| 既有本机聊天管理 | 本人请求实际创建桌面聊天，首任务执行且结果和列表经本人确认 | 干净新装无需配置即可获得相同能力 |
| 既有本机设置页 | 暂停、恢复、状态显示与服务重启后的关闭状态保持 | 关机或休眠期间继续收发 |
| 独立仓库初始整理 | 干净检出、依赖安装、配置初始化、Hook 生成与隔离检查 | 独立新机器人从零安装的真实端到端往返 |

完整测试方法可从仓库运行：

```sh
npm ci
npm run check
npm test
# 安装了 Google Chrome 时额外运行：
npm run test:mermaid
```

测试数量会随代码变化，当前结果以运行输出和公开后的 CI 为准。私密机器上的回执、聊天标识和日志不会作为公开仓库附件。

## 明确限制与待验证项

- 飞书答案通过新用户消息回到聊天；**当前不会自动提交或关闭桌面原生问题框**。同步阻塞提问没有接入。
- 导航另发卡片已经实现并部署，手机端新的完整操作体验仍待单独确认。
- 独立新机器、新飞书应用从零安装的完整往返仍需验证。
- Codex 完整退出后的自动唤起、同一聊天恢复和实际消费仍需验证。
- 断网、休眠恢复及长期运行并没有形成全面兼容承诺。结果未知的操作不会自动重投。
- 普通审批继续使用 Codex 原有机制；仓库内的固定命令实验代码不是通用手机审批功能。
- 桌面与飞书同时答题的竞争不能靠轮询完全消除，避免在两端同时提交。

## 升级后建议复验

先备份私密运行目录并停止旧进程，按[发布维护](releasing.md)更新源码及依赖。使用无敏感内容的聊天，依次检查「当前聊天」→ 发任务 → 桌面实际执行 → 飞书收到回复。启用了图片、问题或新建功能时，分别补做相应真实往返。不要以设置页“已连接”替代这些检查。
