# Illustration sources

Original project illustrations, distributed under the repository MIT license. These are explanatory diagrams, not screenshots or official platform logos.

- `overview.svg`: message routing, Mac boundary, and final-response return path.
- `question-flow.svg`: optional async-question flow and the native desktop prompt limitation.
- `social-card.svg`: 1200 × 630 social preview source; render to PNG for Open Graph consumers.
- `favicon.svg`: abstract connection mark.

SVGs contain accessible titles/descriptions and use system fonts, including Chinese fallbacks. Keep the adjacent documentation as the text equivalent for small screens. Change the diagram and the text together when behavior changes.
